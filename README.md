# 🛒 StoreEase — Modern E-Commerce & Product Dashboard

A production-style, responsive React application built with modern web technologies, advanced product filtering, search, sorting, pagination, authentication UI, and centralized routing.

## 🚀 Features
- **Multi-Page Architecture:** Built with React Router for seamless public and protected routing.
- **Advanced Product Catalog:** Real-time search, multi-category filtering, multi-conditional sorting (Price & Name), and pagination (8 items per page) optimized with `useMemo`.
- **Centralized Authentication State:** Mock authentication flows with protected route protection using Context API.
- **Service Layer Pattern:** Clean separation of API handling and business logic.
- **Responsive UI:** Styled using Tailwind CSS for clean layout scaling across mobile, tablet, and desktop viewports.

## 🛠️ Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **Validation / Forms:** React Hook Form & Zod
- **Version Control:** Git & GitHub
